 🛒 Full-Stack E-Commerce Web Application

A full-featured, responsive E-commerce platform built with the MERN stack (MongoDB, Express.js, React, Node.js). The project includes user authentication, dynamic product catalog, shopping cart, Stripe payment gateway, and a dedicated admin panel for inventory and order management.

---

 🚀 Features

 User End (Storefront)
- User Authentication: Secure JWT-based signup, login, and profile management.
- Product Browsing: Filter products by category, search by name, and sort by price.
- Shopping Cart: Real-time cart updates (add, update quantities, delete).
 - Secure Checkout**: Integrated **Stripe** payment processing for seamless card payments.
- Order Tracking: Order history with real-time status updates.
- Responsive UI: Optimized for mobile, tablet, and desktop screens.

 Admin Dashboard
- Product Management: Add, update, and remove products with image uploads.
- Order Management: Track customer orders and update delivery statuses (Processing, Shipped, Delivered).
- Inventory Control: Live stock tracking.

---

 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS / CSS Modules, Axios, React Router
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose ODM
- **Payments**: Stripe API
- **Authentication**: JSON Web Tokens (JWT) & Bcrypt
